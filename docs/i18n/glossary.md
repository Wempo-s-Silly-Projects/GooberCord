# Approved glossary — per-language terms

Seeded on the FSF translations-directory concept. A translator who violates a
row here has introduced an error, not a preference: these terms are law.

Wording laws (from the owner's framing, carried from AGPLv3/license law):

- Copy never says "open source", "FOSS", or "intellectual property".
  - The licensed-software concept reads **"free (libre) software"** — always the
    parenthetical pair, so "free as in freedom, not price" is self-defining.
  - The zero-cost concept (where needed) reads **"gratis software"** /
    language-specific form below — DISTINCT rows, never collapsed into "free".
- "AGPLv3" stays verbatim-English in every locale — license names are proper
  nouns; translators add the local-language footnote if they must explain it.
- No "cloud" in copy — say "stored on our own infrastructure" (gc) / "on the
  server software we run" (accounts/forum).
- No "piracy"/"protect" framing in any user copy.

Language notes (why the odd cells):

- **tr** — "özgür yazılım" (free-libre) vs "ücretsiz yazılım" (gratis) is the
  distinction the free-software community in Turkish uses; never drop "libre"
  into "ücretsiz" — that would erase the freedom meaning.
- **hi** — the community's settled form is "स्वतंत्र सॉफ़्टवेयर" (swatantra =
  independent/libre); "मुफ़्त" alone means gratis, so the libre row keeps the
  parenthetical pair: "मुफ़्त (स्वतंत्र) सॉफ़्टवेयर".
- **ru** — "свободное программное обеспечение" (freedom- sense) is the FSF-cited
  form; the short form "свободные программы" is the accepted abbreviation.
- **pt** — keep "software livre" (community form); "gratuito" is strictly the
  price row, never the freedom row.
- **de** — "Freie Software" is capitalized because "frei(e)" heads the term,
  not sentence position; "kostenlose Software" is the gratis row.

Notes for the expanded cells:

- **sv / cs / hu / pl** — the free- vs gratis- distinction rides the classic
  pair set (fri/gratis, svobodný/bezplatný, szabad/ingyenes, wolne/darmowe);
  translators must never collapse each pair into its single counterpart.
- **el** — Greek famously has no single everyday "free" covering freedom; the
  settled pair is ελεύθερο (freedom) vs δωρεάν (price), with ιδιόκτητο as the
  proprietary term.
- **he** — תוכנה חופשית (freedom) vs תוכנה חינמית (price) vs תוכנה קניינית:
  RTL script; the never-translate brand list stays LTR-embedded inside the
  RTL sentence and may need directionality marks in final copy.
- **id** — "bebas" carries the freedom meaning (bekerja sama, bebas);
  "gratis" is only the price row; "berpemilik" (owned) is the settled
  proprietary form.
- **ko** — 자유 (freedom) vs 무료 (free-of-charge); the proprietary cell
  carries both 사유 and 독점 since usage splits by context; pick 사유 in UI
  copy, 독점 only where a contrast to freedom is being drawn explicitly.
- **uk** — mirrors the ru community pair (вільне / пропрієтарне) with its own
  standard spelling; do not copy ru word order.

## Wave-4 register rows (gc bundle, ar, 2026-11-17)

- **ar register: Modern Standard Arabic, declared and held** — product tone
  throughout; controls ride the masdar style (حفظ، إرسال، حذف).
- **Latin digits, declared**: {{count}} and every other numeric
  interpolation stays Latin-digit — the loader does not localize numerals,
  and building Arabic-Indic digits into strings would freeze them.
- **RTL is data-only for the i18n lane**: no bidi control characters in any
  row (the law forbids them machine-wide); the dir/CSS wiring is frontend's
  separate rider; the bundle ships inert under BUNDLE_LANGS like every
  other.
- **brand/technical verbatim**: GIF/GIFs, epoch, @everyone, #rrggbb, MiB,
  MP3/OGG, Enter/Shift+Enter, Goober+/Goober Coins/Wempo Accounts.

Row notes:

- **ar branch ruling (the one-arm flex)**: under Latin digits the zero/one/
  two/many/other shapes all collapse onto the numeral+singular form (the
  written dual needs no numeral, and صفر rides singular) — Arabic's only
  VISIBLE count flex is the 3–10 noun plural. Each branched family therefore
  ships exactly one `_few` arm plus an explicit `_other` row equal to base
  (the ru base==_other convention). Route table per family: zero→base,
  one→base, two→base, few→`_few`, many→base, other→`_other`(=base) — every
  seat route lands a real row, the BRANCH-SET audit's strongest reading.
- **emoji takes the full MSA term (الرموز التعبيرية)** over the إيموجي
  borrow — register hold; the term is long but the tabs carry it.
- **epoch stays the technical word in English** in ar too, per the wave-1/2
  rows — it is a key format name, not prose.
- **prune.result / timeout.choice / ears compose numeral-safe** ("طُرد:
  {{count}}." colon-label style like ru's "Выгнано:", "{{count}} د" the
  minute abbreviation, ears reworded to a definite-plural noun with the
  numeral last) — the measure-invariant composition class, same row-notes
  rationale as ru's serverRow/prune.result.

Platform-noun law (reviewer rider, folded into the wave-4 cadence):

- **PLATFORM NOUNS are technical-verbatim in EVERY locale** — @everyone,
  @here, epoch strings, permission-bit names: users resolve roles by the
  exact string, so no bundle translates them. The reviewer's ASCII
  server-class scan's blind direction (a non-Latin script silently
  translating the noun) is now documented and catches this class
  procedurally; the first and only victim was zh's "@所有人" (roles.count
  + overwrites.order), restored to "@everyone" in the wave-4 cadence —
  ja and ar held the verbatim from row one.
